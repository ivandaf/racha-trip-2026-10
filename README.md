## Маршрут по дням

### 30.10 · пт · Тбилиси → база (день дороги)
`Ранний старт 7:00–7:30. Тбилиси → Сачхере → перевал Хихата → Баракони → база. 3,5–4 ч + остановки, до заката ~18:20. Обед в Сачхере или Амбролаури.`

**Точки:** Тбилиси → Сачхере → перевал Хихата → Баракони → база (ужин/вино: Chveni puri da gvino, Wine House Khvanchkara)

**Время:** старт 7:00–7:30, в пути 3,5–4 ч + остановки, прибытие до заката ~18:20. Обед в Сачхере или Амбролаури

**Погода:** в долине мягко и по-осеннему, на перевале Хихата холоднее и возможен туман/сырость — заложить запас времени на серпантины

### 01.11 · вс · выезд через Лечхуми
Алпана → Орбели → Цагери → Окуреши → Хвамли → обед → Тбилиси. Хвамли — только если накануне не было снега/дождя.

**Точки:** Алпана → Орбели → Цагери → Окуреши → Хвамли → обед → Тбилиси (обед Doli, Кутаиси; запасной — Otia's Ezo + пещера Прометея)

**Время:** длинный день дороги домой; подъём на Хвамли — 2–4 ч туда-обратно от парковки, плюс дальний перегон до Тбилиси

**Погода:** Хвамли — только если накануне не было снега/дождя и нет тумана (плато открытое, тропа местами скользкая). При плохой погоде сразу на запасной вариант
